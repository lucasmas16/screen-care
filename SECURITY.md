# Segurança

Não inclua credenciais nem dados de usuários em issues ou pull requests. Reproduza o problema em ambiente descartável com dados sintéticos.

O canal privado de vulnerabilidades está ativado. Use [Report a vulnerability](https://github.com/lucasmas16/screen-care/security/advisories/new), na aba Security do repositório. Não publique detalhes exploráveis em issues públicas enquanto o relato estiver em análise. Esta organização de arquivos não substitui uma auditoria de segurança do aplicativo.

A versão preparada para publicação é a 1.4.1. Consulte o [escopo, evidências e limites da revisão](docs/REVISAO-SEGURANCA-1.4.1.md). Relatos devem incluir versão do Windows e do aplicativo, passos mínimos e arquivos sintéticos, sem preferências, fotos ou logs pessoais completos.
